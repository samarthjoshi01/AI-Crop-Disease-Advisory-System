# AI-Powered Crop Disease Detection and Farmer Advisory System

## TBI-GEU Summer Internship Program 2026

### Project Overview

The AI-Powered Crop Disease Detection and Farmer Advisory System is an intelligent web-based platform designed to help farmers identify crop diseases using Artificial Intelligence and Computer Vision.

Farmers can upload images of affected crops, and the system will analyze them to predict diseases and provide treatment recommendations, preventive measures, and farming guidance.

### Objectives

- Detect crop diseases using AI.
- Provide treatment recommendations.
- Offer preventive measures.
- Support farmers through an AI-powered advisory assistant.
- Maintain crop health records.
